Account verwijderen
⚠️ Dit is de meest drastische actie mogelijk.
Alle templates, submissions, foto's, gebruikersprofielen, rollen en alle login-accounts worden permanent verwijderd. Na afloop wordt je uitgelogd en is de volledige app leeg.

Plak dit in Supabase → SQL Editor en voer uit 
CREATE OR REPLACE FUNCTION public.delete_all_data_and_users()
RETURNS void LANGUAGE plpgsql SECURITY DEFINER SET search_path = public AS $$
BEGIN
  IF NOT get_is_admin() THEN
    RAISE EXCEPTION 'Access denied: admin role required';
  END IF;
  DELETE FROM photos;
  DELETE FROM submissions;
  DELETE FROM templates;
  DELETE FROM user_profiles;
  DELETE FROM roles;
  DELETE FROM auth.users;
END;
$$;
GRANT EXECUTE ON FUNCTION public.delete_all_data_and_users() TO authenticated;
